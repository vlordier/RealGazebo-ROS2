realgazebo.contracts

Single source of truth for RealGazebo data contracts.

All communication formats (ROS2 topics, dora-rs dataflow, UE5 UDP packets) are derived from these Pydantic models. Never define the same field in multiple places.

Usage:

from realgazebo_schema.contracts import VehiclePose pose = VehiclePose(x=1.0, y=2.0, z=-5.0) ros2_msg = pose.to_ros2_msg() # → px4_msgs/VehicleLocalPosition dora_bytes = pose.to_json() # → dora-rs dataflow udp_packet = pose.to_ue5_packet() # → bytes for UE5 UDP socket
